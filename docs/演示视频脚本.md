## 录制前准备（5 分钟）

| 项 | 做法 |
| --- | --- |
| 窗口 | 浏览器 100% 缩放，窗口铺满 1920×1080；隐藏书签栏、状态栏、桌面图标 |
| 数据 | 先点一次「载入样例台账」确认能出 14 条问题，再清空重录，保证一次过 |
| 字体 | 系统缩放 100%，避免录出来发虚 |
| 鼠标 | 打开鼠标点击高亮（PowerPoint 录屏或 Windows 自带）；移动放慢，每个操作停 0.5 秒 |
| 隐私 | 关掉微信、QQ、浏览器其他标签；用干净的用户目录 |
| 音频 | 口播用手机或耳机麦单独录，后期对齐；旁白稿见每段 |

**统一的录屏节奏**：操作 → 停 0.5 秒 → 结果出现 → 口播解释。不要一边点一边说，后期对不上。

**画面**：深蓝底，居中大字「票准 TaxSure」，下方小字「中小企业发票合规 AI 审计官」。淡入 0.5 秒。

**口播**：

## 02 · 产品是什么（0:18–0:40）

**画面**：首页全貌。鼠标依次悬停「政策问答」「发票体检」「税费试算」三个页签，各停 1 秒。

**口播**：
> 票准做三件事：把发票台账逐行体检出风险；用大白话问出应缴税额，给出可复算的明细；
> 每一条结论，都落到具体的法规条文上。
> 先说清楚一件事——AI 在这个系统里不算数，也不算事实。它只负责听懂你在问什么，以及把结果讲成人话。

**字幕**：体检 / 试算 / 问答 ｜ AI 不算数，AI 只找依据

## 03 · 演示一：政策问答（0:40–1:25）

**画面**：
1. 点「政策问答」页签。
2. 点示例问题「我这个季度开了 28 万的普票，小规模纳税人，要交多少税？」（自动填入）
3. 点「提问」，等 1 秒，结果出现。
4. 鼠标沿着「试算结果」表格划过：计税依据、税率、金额、说明。
5. 滚到「检索到的依据」，指向《财政部 税务总局公告 2023 年第 19 号》第一条。

**口播**：
> 提一个问题，系统做三件事。
> 第一，判断这是「算税」而不是「查政策」；第二，调规则引擎把账算出来——28 万没到季度 30 万的免征线，
> 普通发票部分免征，所以增值税是 0；第三，去法规库里把依据找出来，附在下面。
> 注意这两个数字：本季应纳税费合计 0 元，和距离免征线只剩 2 万元的提醒。
> 跨过那条线不是「超出部分缴税」，是全额计税。多开一块钱，多缴三千块。
> 这不是我们编的，是条文这么规定的。

**字幕**：28 万 ≤ 30 万 → 普票免征 ｜ 跨线是全额计税，不是超出部分

## 04 · 演示二：发票体检（1:25–2:05）

**画面**：
1. 点「发票体检」页签，企业名称与期间已填好（重庆山城智造科技有限公司 / 2026Q4）。
2. 点「载入样例台账（内置 8 行，埋了 6 类问题）」。
3. 结果出现：风险分 80、高危 4、中危 5……
4. 鼠标从上往下划过问题清单，在「建筑服务发票备注栏为空」那行停住，指向「判定依据 R09」。

**口播**：
> 第二个场景：上传台账，逐行体检。
> 这份样例里我故意埋了六类问题——重复的发票号、咨询服务开成 13%、税额算错、抬头少了两个字、
> 七月的票混进四季度、建筑服务备注栏空着。
> 系统把九行全过了一遍，列出十四条问题，每条都告诉你：第几行、哪里不对、依据哪一条、该怎么改。
> 最后这张「建筑服务备注栏」，是进项转出的高发区——票是真的，业务也是真的，但票面不合规，就是不能用。

**字幕**：9 行台账 → 14 条问题 ｜ 每条都带「第几行 + 依据 + 建议」

## 05 · 演示三：税费试算（2:05–2:35）

**画面**：
1. 点「税费试算」页签。
2. 把「本季不含税销售额」从 280000 改成 320000，点「试算」。
3. 结果：增值税 3,200；下方出现橙色提醒。

**口播**：
> 第三块是试算。把销售额从 28 万改成 32 万，跨过免征线。
> 增值税变成 3,200 元——是全额乘以 1%，不是超出的 2 万乘以 1%。
> 这个跳档提示，是我们认为最值钱的一行字。因为中小企业最容易在这里做错决策：以为多开两万只多缴两百。

**字幕**：28 万 → 0 元 ｜ 32 万 → 3,200 元（全额计税）

## 06 · 技术亮点（2:35–2:52）

**画面**：切到 BP 第 7 页（五层架构图），鼠标指向「能力层」，再指向「编排层」。

**口播**：
> 技术上有两个不常见的选择。
> 第一，检索没用向量库，用 BM25——法规库只有二十七条，BM25 是确定性的，命中哪几个词、得分多少都能打印出来，
> 评委可以现场验证。第二，所有数字由规则引擎算，模型碰不到算术。
> 所以换个模型，产品还是这个产品；关掉模型，三个功能一个都不少。

**字幕**：BM25 可解释检索 ｜ 规则引擎算数 ｜ 无 API Key 也能跑
